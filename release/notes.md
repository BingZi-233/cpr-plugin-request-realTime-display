# v1.0.7

请求日志改为铺满可用宽度，去掉密钥和模型筛选。每一次请求从进入开始记录，完成或出错时更新同一条，并统计 tok/s、输入缓存率和写入缓存率。

- 页面不再限制 1180px，统计和表格按整行排布
- 进行中、完成、错误分列计数；失败、拒绝、取消和未完成都算错误
- tok/s = 输出 Token / 上游响应耗时，缺少上游耗时时用总耗时
- 输入缓存率 = 缓存读取 / 输入 Token，写入缓存率 = 缓存写入 / 输入 Token
- 日志保留最近 200 条请求

# v1.0.6

实时请求日志页面改用 Codex Proxy UI 组件库，并继续适配不同屏幕尺寸和宿主明暗主题。

## 修复与改进

- 桌面端保持紧凑的请求日志表格布局
- 平板宽度自动调整摘要卡片和筛选区域
- 手机宽度将日志转换为带字段标签的卡片行
- 长请求 ID、密钥名称和模型名称会自动换行
- 卡片、筛选区、表格和状态标签跟随宿主主题变量切换
- 摘要卡片、筛选控件、状态标签和空状态统一使用 `@codex-proxy/ui`

## 升级说明

- 提供 Linux x86_64、Linux aarch64、macOS aarch64 安装包及各自的 SHA-256 校验文件
- 请选择与宿主运行平台一致的 `.tar.gz` 安装包
